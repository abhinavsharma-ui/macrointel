# Live Trading Readiness Plan

Current public snapshot: 2026-05-19

The current system is paper-first. This document describes what must be true before any live trading switch is considered. It is not permission to enable live trading.

## Current State

- US lane uses Alpaca paper credentials by default.
- NSE lane is paper and separate from Alpaca.
- Daily US signals are generated by ML thresholding plus hard gates plus LLM risk review.
- Paper execution evaluates stop loss, profit target, and hold-period exits.
- Dashboard live marks come from Alpaca latest bars.
- Stock Diagnostic is research and explanation tooling.

## Live Preconditions

Before live trading:

1. Broker mode must be reviewed in code and environment.
2. `ALPACA_PAPER` must remain `true` until an explicit live change is approved.
3. Stop loss and target behavior must be verified against a controlled paper run.
4. ETF and leveraged ETF blocklists must be verified.
5. Daily signal threshold and top-N capacity must be printed in the run log.
6. LLM key rotation must be healthy and not silently keeping unfiltered candidates.
7. Dashboard live prices must match broker/account marks within expected tolerance.
8. Open positions must reconcile against broker state.
9. Cron must run each stage once, in order, without overlapping duplicate execution.
10. A manual kill path must be documented and tested.

## Paper Validation Checklist

Run:

```bash
cd project
source ../venv/bin/activate
python scripts/fixed_return_daily_signals.py
python scripts/fixed_return_paper_execute.py
python scripts/intraday_mark_to_market.py --force
```

Verify:

```bash
python - <<'PY'
import json
from pathlib import Path
signals = json.loads(Path("reports/fixed_return_daily_signals.json").read_text())
positions = json.loads(Path("reports/fixed_return_open_positions.json").read_text())
print("threshold:", signals.get("threshold"))
print("top_n:", signals.get("top_n"))
print("signals:", len(signals.get("signals", [])))
print("open_positions:", len(positions.get("positions", [])))
PY
```

Dashboard checks:

- Open Positions current price updates.
- P&L attribution matches open positions.
- Stop-loss candidates are visible.
- Today's Signals date is current.
- Stock Diagnostic runs with and without Force LLM.

## Failure Modes To Block Live

Do not go live if:

- Any ETF/leveraged ETF passes selection.
- A signal below `SIG_THRESHOLD` becomes a production trade.
- LLM API failures cause all candidates to be kept without an explicit operator decision.
- Stop-loss exits do not close in paper.
- Dashboard prices are stale while positions are open.
- Cron produces duplicate orders.
- Runtime secrets are missing, copied into git, or stored in shell history.

## Live Switch Shape

If live mode is ever approved, it should be a separate branch and explicit deployment, not an accidental `.env` edit. The switch should include:

- A code-level broker mode assertion.
- Reduced max position count.
- Reduced position sizing.
- Broker-side order confirmation.
- Pre-market dry run.
- One-symbol live canary only after paper reconciliation.
- Immediate rollback command.

Until then, treat this repo as a paper trading and research system.
